Mixed languages

Switch language? So does it.

Whisper reads a file in one language and quietly translates anything else. Mova Flow notices the stretches in another language and transcribes them as they were spoken — so the English part of a Ukrainian interview stays English.

  • Works for every file, not only calls
  • Tuned on labelled recordings: it never rewrote the main language in testing

  • Recovered automatically after a crash or a quit mid-call
  • A busy host is retried, a lost connection waited out

Host + clients

One GPU. Every laptop.

One machine with a graphics card holds the model and does the work; every other laptop on your Wi-Fi is a light client that finds it on its own.

  • Host on Windows (CUDA or CPU) or Apple Silicon (Metal)
  • Shared secret + short-lived tokens; LAN only, never the internet
  • “Scan network” finds the host — no IPs to type

Everything else

All of it on hardware you already own.

Fully local recognition

whisper.cpp with a voice-activity model, so silence never turns into hallucinated text. Audio never leaves your network.

Record from any app

On macOS, pick just the app the call is in — notifications and music stay out. Start from the tab, the tray or the Dock.

Any Whisper model

From tiny (~75 MB) to large-v3 (~3 GB), or your own .bin. The right engine build downloads on its own, checksum-verified.

Any file

Drop in mp3, wav, m4a, mov and more — anything that isn't WAV is converted on your machine first.

Private history

A client's history stays on the client; the host's history is reachable only from the host itself.

Lives in the tray

Closing the window keeps the host serving; record a call straight from the tray or the Dock.

Updates on your terms

You're told when a version is out and choose when to install — or let it update itself.

English & Ukrainian UI

Switch the interface language in Settings, along with the microphone and update options.

See it running

The real interface — uploads, call recording, history, server setup and settings.

Built to stay on your network

A shared secret exchanges for a short-lived bearer token on every request, and the server only answers on your local network. History is gated to 127.0.0.1 at the code level — a client's history can never reach the host, token or not.
